## 📖 今日核心知识（生活化解释）

**1. 算法 = 有顺序、能重复、会做判断的"操作说明书"**
你妈让你"把碗洗干净"——这是个任务。怎么写进电脑？"拿起碗 → 冲水 → 挤洗洁精 → 擦 → 冲干净 → 放下 → 如果还有碗，重复"。这就是算法：**顺序 + 循环 + 判断**。你在C语言学的那三样，正好就是算法的三块积木。

**2. "遍历 + 比较"是算法世界的万能钥匙**
你已会数组遍历，这非常关键。绝大多数入门题的套路就是：**走一遍所有元素，边走边记录一个"当前最好/最大/最小/最符合条件"的答案**。就像逛街比价，你不用记住每个价格，只需一直揣着"目前最便宜的那个"。

**3. 变量就是你的"小本子"**
刷题时最常用的两样东西：一个**计数器**（数了几个）、一个**暂存器**（目前最优是谁）。写代码前先在纸上想清楚"我需要几个小本子、每个本子记什么"，写起来就不会乱。

## 💻 今日实战任务（必须手写，禁止AI代写）

**题目：数组中的"最大值与它的位置"**

> 给定一个整数数组，找出其中**最大的数**，并输出这个最大数以及它**第一次出现的下标**（下标从 0 开始）。

**输入示例：**
```
8
3 7 2 9 5 9 1 4
```
（第一行是元素个数 n，第二行是 n 个整数）

**输出示例：**
```
9 3
```
（因为最大值是 9，它第一次出现在下标 3 的位置）

**编码要求（自己动手，一步步来）：**
1. 先在纸上写清楚：我需要几个"小本子"变量？分别记什么？（提示：至少两个）
2. 初始化这两个变量时想清楚——如果一开始就设成 0，会不会踩坑？（想一下全是负数的情况）
3. 用 `for` 循环遍历一遍，在循环里做"比较 + 更新"。
4. 注意题目要的是**第一次出现**的位置，遇到相同最大值时该怎么处理？（这是今天的思维陷阱，想明白再写）

**写完后请回答我一个问题：** 为什么更新最大值和更新下标要"绑在一起"在同一个 `if` 里完成？想清楚这个，你就摸到"遍历+比较"的门了。
