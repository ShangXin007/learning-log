## 📖 今日核心知识（生活化解释）

1. **数组 = 一排连号的储物柜**
   想象你有一排储物柜，编号从 `0` 开始：`柜0、柜1、柜2...`。数组就是这一整排柜子，`int a[5]` 表示"我要 5 个连着的柜子，每个柜子放一个整数"。**关键：编号从 0 开始，不是 1！** 这是新手最常摔的坑。

2. **下标（索引）= 柜子编号**
   想拿第 3 个柜子里的东西，写 `a[2]`（因为从 0 数）。`a[0]` 是第一个，`a[4]` 是第五个。**访问越界**（比如 5 个柜子你摸 `a[5]`）就是去摸不存在的柜子，程序会出乱子。

3. **遍历 = 拿个 for 循环挨个开柜子**
   数组和 `for` 循环是天生一对（你循环已经会了，正好用上）：
   ```c
   for (int i = 0; i < 5; i++) {
       // 这里 a[i] 就是第 i 号柜子
   }
   ```
   把"挨个检查柜子"这件事，用你已经会的循环批量完成——这就是数组的威力。
