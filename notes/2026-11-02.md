## 📖 今日核心知识（生活化解释）

1. **暴力枚举（Brute Force）**
   就像你在一堆钥匙里找能开锁的那把——不玩技巧，挨个试，试到对为止。算法里就是：**把所有可能的情况都用循环列出来，逐个检查**。别嫌它笨，它是所有算法的地基，先会"笨办法"，才能懂"巧办法"。

2. **双重循环 = 枚举"两个东西的组合"**
   一个循环是"一个人挨个走"，两个循环嵌套就是"两个人两两配对"。比如点名：外层循环是A同学，内层循环是B同学，就能枚举出所有"两人组合"。这是今天题目的核心武器。

3. **数组下标与元素的关系**
   遍历数组时，`nums[i]` 是"第几个数"，`i` 是"它的位置"。算法题里经常要**同时用到值和位置**，今天这道题就考这个——记住：位置（下标）是数组给你的隐藏信息。

## 💻 今日实战任务（必须手写，禁止AI代写）

> **题目：两数之和（LeetCode 第 1 题 · 经典入门）**

给定一个整数数组 `nums` 和一个整数目标值 `target`，请你在数组中找出**和为目标值 `target` 的那两个整数**，并返回它们的**数组下标**。

**要求：**
- 假设每种输入只会对应一个答案，且同一个元素不能重复使用。
- 你可以按任意顺序返回答案。
- 数据规模很小，**用你今天学的"暴力枚举（双重循环）"来解**，不要用哈希表（那是后面的内容）。

**示例：**
```
输入：nums = [2, 7, 11, 15], target = 9
输出：[0, 1]
解释：nums[0] + nums[1] = 2 + 7 = 9，所以返回下标 0 和 1。
```

**手写提示（先想清楚再敲键盘）：**
1. 外层循环 `i` 从 0 走到末尾，代表"第一个数"；
2. 内层循环 `j` 从 `i+1` 开始走，代表"第二个数"（为什么从 `i+1` 开始？想想看，能不能避免重复配对和"自己加自己"）；
3. 判断 `nums[i] + nums[j] == target`，成立就输出 `i` 和 `j`。

**提交格式：**
- 贴出你的完整 C 代码；
- 在代码注释里写一句：**"我为什么让 j 从 i+1 开始？"**（这题的关键理解点，答对说明你真懂了）
