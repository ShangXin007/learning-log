## 📖 今日核心知识（生活化解释）

**1. 二分查找 = "猜数字"游戏**
你朋友心里想 1~100 的一个数，你每猜一次他说"大了/小了"。你绝不会从 1 开始一个一个猜（那是 O(n) 暴力），你会猜 50，再猜 25 或 75……**每次砍掉一半**，最多 7 次必中。这就是 O(log n)。前提：**数组必须有序**。无序数组上的二分，是考试里最常见的送命题。

**2. 边界三件套 —— 二分翻车 90% 在这里**
- `while (left <= right)` 对应"闭区间"写法，`right = mid - 1`；
- `while (left < right)` 对应"左闭右开"写法，`right = mid`；
- **两套写法不能混用**，混了必死循环。
- `mid = left + (right - left) / 2` 而不是 `(left + right) / 2`——后者在超大数组下会**整数溢出**（这就是"数组越界/溢出防范意识"的实战版）。

**3. 从 O(n) 到 O(log n) 的优化思维**
暴力法：遍历每个元素看等不等 → O(n)。
二分法：利用"**有序**"这个信息，每次排除一半 → O(log n)。
**记住一句话：看到"有序数组 + 查找/定位"，先想能不能二分。** 这就是"优化"的本质——不是技巧炫技，而是**榨干题目给的隐藏信息**。

### 题目：搜索插入位置（LeetCode 35 简化版）

给定一个**升序无重复**的整数数组 `nums` 和一个目标值 `target`。如果 `target` 在数组里，返回它的下标；如果不在，返回它**应该被插入的位置**（即第一个大于 target 的元素下标；若都比它小，返回数组长度）。

**示例：**
- `nums = [1,3,5,6], target = 5` → 返回 `2`
- `nums = [1,3,5,6], target = 2` → 返回 `1`
- `nums = [1,3,5,6], target = 7` → 返回 `4`

### 要求（逐条满足，否则不算过关）：

1. **先写暴力 O(n) 版**：遍历一遍，找到第一个 `>= target` 的位置。写完后，在注释里写一句话：*"这里可以优化到 O(log n)，因为数组有序。"*
2. **再写二分 O(log n) 版**：用"左闭右开"写法（`while (left < right)`，`right = mid`）。
3. **边界自测**（这是你的薄弱点，必须做）：自己构造并跑通以下 5 组用例，把结果写进代码注释——
   - 空数组 `[]`, target = 3
   - 单元素 `[1]`, target = 1
   - 单元素 `[1]`, target = 2
   - target 比所有元素都小：`[3,5,7]`, target = 1
   - target 比所有元素都大：`[3,5,7]`, target = 9
4. **大括号纪律**：每一个 `if / while / for` 哪怕只有一行，**也必须加 `{}`**。写完用眼睛扫一遍，漏一个罚自己重写整题。
