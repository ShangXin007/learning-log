## 📖 今日核心知识（生活化解释）

**1. 什么是「快慢指针」**
想象你和朋友在操场跑步，你在慢跑道、他在快跑道，两个人同时从起点出发。你俩速度不一样，所以**跑着跑着，两人之间的差距会越来越大/越来越小**。算法里，就是用两个"指针"（其实是数组下标）以不同速度移动，来制造这种"差距变化"——差距一变，就能解决很多问题。

**2. 为什么它好用（今天这道题的灵魂）**
很多"原地修改数组"的题，正是靠慢指针"守住结果区"、快指针"负责探路"来完成的。慢指针只在"找到合格元素"时才前进一步，于是新数组的前 N 个坑位就被一个个填好了，**不用额外开一个数组**。

**3. 数组下标和你已有的知识**
你已经会 `for` 循环遍历数组了。快慢指针只是把"一个 `i`"拆成"两个变量 `slow`、`fast`"，`while` 循环里手动控制它俩走。**没有新语法，只有新思路**——这就是算法入门最好的切入点。

### 🎯 题目：移除元素（对应 LeetCode 27 / 洛谷同类题）

给你一个数组 `nums` 和一个值 `val`，请**原地**移除所有数值等于 `val` 的元素，并返回移除后数组的新长度。

要求：
- 不要使用额外的数组空间（**必须原地修改** `nums`）。
- 元素的顺序可以改变。
- 返回的新长度之前的元素，必须是不等于 `val` 的元素（顺序无所谓）。

**示例：**
```
输入: nums = [3, 2, 2, 3], val = 3
输出: 2
解释: 函数应返回新长度 2，且 nums 的前两个元素为两个 2。
```

```c

    // 在这里用快慢指针实现
}

```

### 🧭 提示（先别看，自己想 20 分钟卡住了再看）

<details>
<summary>点我展开提示</summary>

1. 定义两个变量 `slow = 0`（慢指针，指向"新数组"该填的位置）和 `fast`（快指针，从头遍历）。
2. `fast` 每走一步，判断 `nums[fast]` 是不是 `val`：
   - **不是** `val` → 它就是合格元素，填到 `nums[slow]`，然后 `slow++`。
   - **是** `val` → 跳过，`slow` 不动。
3. `fast` 遍历完，`slow` 的值就是新长度。
