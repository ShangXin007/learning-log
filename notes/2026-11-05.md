## 📖 今日核心知识（生活化解释）

1. **什么是"算法"？**
   算法不是高深公式，就是「解决问题的步骤」。比如找班里最高的同学：你不需要背公式，只需要挨个问"你多高？"，记下当前最高的那个，问完一圈就有答案了。这就是算法——**遍历 + 记录**。

2. **"一次遍历"思维（O(n) 扫描）**
   很多题的最优解就是"从头到尾扫一遍"。用一个变量记住"我目前见过的最佳答案"，每扫到一个新元素就和它比较，谁更优就更新它。这就像翻一叠牌找最大牌，你手里永远只留当前最大的那张。

3. **边界与初始化（新手最容易翻车的地方）**
   找最大值时，那个"当前最大"变量怎么初始化？**不要随便填 0**——如果数组全是负数，填 0 就错了。正确做法：初始化为数组第一个元素（或一个极小值如 `-2147483648`）。这个小坑 90% 的人第一次都会踩。

## 💻 今日实战任务（必须手写，禁止AI代写）

### 题目：数组中的最大值与最大值的位置

**输入**：第一行一个整数 `n`（1 ≤ n ≤ 100），第二行 `n` 个整数 `a[i]`（-10000 ≤ a[i] ≤ 10000）。

**输出**：两个整数 —— 最大值，以及它**第一次出现**的下标（下标从 0 开始，注意是"第一次出现"）。

**样例输入**：
```
5
3 -7 3 9 9
```
**样例输出**：
```
9 3
```

**要求（请严格遵守）**：
1. **必须手动敲代码**，不要复制粘贴、不要让 AI 代写。
2. 用 `for` 循环**只遍历一遍**数组完成（禁止先找最大值再找位置这种两遍遍历）。
3. 必须处理「最大值重复出现只取第一次」的情况（用 `>` 而不是 `>=`）。
4. 写完自己手动推演一遍样例，确认输出 `9 3` 后再算完成。
5. 卡住超过 15 分钟就看下面提示，但**尽量不要看**。

**卡壳提示（实在写不出再看）**：
> 思路：定义 `max = a[0]; pos = 0;`，然后 `for(i=1; i<n; i++)`，若 `a[i] > max` 则更新 `max = a[i]; pos = i;`。最后输出 `max` 和 `pos`。
